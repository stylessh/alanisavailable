# Alan is available

My own take on the products I'd love to work on.

## Develop

```bash
pnpm dev
```

## Products

Each product lives in its own folder, `src/products/<slug>/`, with its own
components, style guide, content and assets (`public/products/<slug>/`). See
[src/products/README.md](src/products/README.md) for the layout and how to add
one. Cards are styled from the product's `metadata`: `background` (any CSS
background, gradients included) and `foreground`, plus optional
`backgroundDark` / `foregroundDark`, `flat` and `grain`.
